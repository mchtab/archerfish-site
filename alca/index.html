Project Alca

Dwg no.AF-A01

Project Alca is a personal assistant workspace that, with the owner's permission, reads the owner's own Gmail and Google Calendar so an agent can find a message, draft a reply or check a schedule. Every email it sends and every event it creates or changes is shown as a card first, and goes ahead only after the owner approves it.
