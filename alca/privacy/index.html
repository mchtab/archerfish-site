Project Alca privacy policy

Last updated 12 October 2026

Alca is a personal tool that runs on its owner's own Mac. It is not offered to the public, and the only Google accounts it connects are its owner's. This page says what Alca does with data from those accounts.

What Alca accesses

  • Gmail: messages, threads, drafts and labels, so an agent can search mail, read a message, draft a reply, and send or label mail once the owner approves.
  • Google Calendar: calendars and events, so an agent can check a schedule and create, change or answer events once the owner approves.

Alca reads this data only when an agent session the owner started asks for it. It does not sync or copy a mailbox or calendar in the background.

Where it goes

  • Data read from Google is shown in the owner's session on their own devices and kept in that session's history on the owner's Mac.
  • It is passed to the AI model the owner chose to run that session, only to carry out the owner's request.
  • Sign-in tokens are kept encrypted on the owner's Mac, with the key in the macOS Keychain. They are never written to logs or sent anywhere except Google.
  • Alca has no server of its own on the internet. Archerfish does not receive, sell or share this data, and does not use it for advertising or to train AI models.

Google API Services User Data Policy

Alca's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove an account in Alca's settings, which revokes its token, or at any time from Google Account › Third-party connections.

Contact

Questions go to the support address shown on Alca's Google sign-in screen.
